# Nina — The Bakery

A polished, responsive bakery landing page for Nina, a small artisanal pastry and cake shop. The site is designed to feel warm, premium, and handcrafted, with a clean modern aesthetic and strong product-focused sections.

## Project Overview

This project showcases a boutique bakery brand through:

- a welcoming hero section with product imagery and layered design
- a story/about section highlighting the brand's origin and values
- bakery feature cards emphasizing quality and freshness
- customer testimonials and social proof
- a product/order form for custom bakery requests
- contact details and Instagram CTA for local pickup and delivery

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Local image assets

## Project Structure

- `index.html` — page structure and content
- `style.css` — full styling, layout, animations, and responsiveness
- `main.js` — interactive behavior like mobile menu, scroll effects, and reveal animations
- `images/` — branding and product visuals

## Features

- Responsive layout for desktop and mobile devices
- Fixed navigation with active section highlighting
- Mobile menu toggle
- Smooth scrolling and subtle reveal animations
- Order form with confirmation state
- Strong visual branding using warm blue and cream tones

## How to Run

Because this is a static website, you can view it by opening `index.html` directly in a browser.

If you prefer a local server, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Notes

This project is ideal for a bakery, cafe, or handmade food brand looking for a stylish landing page that fits both storefront and social commerce needs.
